# DEDUCT

Project page and extended supplementary notes: https://cetin-lab.github.io/deduct/

## Status

The manuscript has been submitted to IEEE Access. The source code, configuration files,
corpus fetch scripts, and test suite will be released in this repository upon acceptance
of the paper, under the PolyForm Noncommercial 1.0.0 license.

Until then, this repository hosts only the project web page (`docs/`).
